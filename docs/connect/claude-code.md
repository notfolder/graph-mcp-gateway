# Claude Code からの接続

受け口の違いと共通の流れは [README.md](README.md) を先に読む。

## 1. 社内の認証局を信頼させる

Claude Code を起動するシェルで、社内の認証局の証明書を読ませる。

```bash
export NODE_EXTRA_CA_CERTS=/path/to/company-ca.pem
```

常に使うなら、シェルの設定ファイル（`~/.zshrc` など）に書く。

## 2. 受け口を登録する

探して使う受け口の例（全部を出す受け口なら URL の `/discovery/` を `/full/` にする）。

```bash
claude mcp add --transport http m365 https://<公開のホスト名>/discovery/mcp
```

両方を使う場合は、名前を分けて 2 つ登録する（例：`m365-full` と `m365`）。

## 3. 認証する

Claude Code の中で `/mcp` を開き、登録した `m365` を選んで認証を始める。ブラウザが開いたら次の順に進める。

1. 本システムの「接続の確認」画面で、クライアントの名前を確かめて「許可」を押す。
2. Entra ID のサインイン画面で社内アカウントでサインインする。
3. 「認証が完了しました」の表示を確かめてブラウザを閉じる。

## 4. 確かめる

Claude Code に「M365 の自分のプロフィールを取得して」と頼む。

- 探して使う受け口では、Claude Code が「ツールを探す」→「引数を調べる」→「実行する」の順に呼ぶ。
- 本人の表示名とメールアドレスが返れば接続できている。

## 補足

- トークンの更新は Claude Code が自動で行う。長く使わずに期限が切れたときは、`/mcp` から認証し直す。
- 登録を消すときは `claude mcp remove m365`。
